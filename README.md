# SafeHer 🛡️

**SafeHer** is an AI-powered personal safety Android app built for women, designed to help users quickly reach out for help in emergency situations with a single tap.

## ✨ Features

- 🚨 **Tap for Emergency** — One-tap SOS button to trigger emergency alerts instantly
- 📳 **Background Protection** — Shake your phone to trigger SOS, even when the app is in the background
- 👥 **Contacts** — Manage a list of trusted emergency contacts
- 📞 **Call Contact** — Instantly call a saved emergency contact
- 📍 **Location** — Share your live location with emergency contacts
- 🔊 **Siren** — Sound a loud alarm to attract attention in danger situations
- 🎙️ **Record Evidence** — Capture audio evidence during an emergency
- 🔦 **Flashlight** — Quick access flashlight toggle
- ⏱️ **Safety Timer** — Set a timer that auto-triggers an alert if not cancelled in time
- 🤖 **AI Assistant** — AI-powered assistant for safety guidance
- 📝 **Report Incident** — Report and log safety incidents
- 💡 **Safety Tips** — Curated safety tips and advice
- 👤 **Profile** — Manage user profile and settings
- 🔐 **Login / Sign Up** — Secure authentication for users

## 🛠️ Tech Stack

- **Language:** Java, Kotlin
- **IDE:** Android Studio
- **Backend & Auth:** Firebase
- **Maps & Location:** Google Maps SDK

## 🚀 Getting Started

### Prerequisites
- Android Studio (latest stable version)
- A Firebase project with `google-services.json` configured
- Google Maps API key

### Setup
1. Clone the repository
```bash
   git clone https://github.com/Sauvi252/SafeHer.git
```
2. Open the project in Android Studio
3. Add your `google-services.json` file to the `app/` directory
4. Add your Google Maps API key in the appropriate config/manifest file
5. Sync Gradle and run the app on an emulator or physical device
